# Google Apps Script — ЖК «Данія» (СвітлоБот)

Моніторинг публічного каналу https://t.me/s/svitlobot_daniya без адміністративного ключа.

1. Відкрити https://script.google.com/home/projects/create під Google-акаунтом.
2. Замінити вміст `Code.gs` кодом із цього файлу: https://github.com/vladimirpovkh-creator/kyiv-outages-dashboard/blob/main/apps-script/Code.gs
3. Зберегти проєкт. У меню функцій обрати `install` і натиснути «Виконати». Надати дозволи на доступ до URL та тригерів.
4. Відкрити «Розгортання» → «Нове розгортання» → тип «Вебдодаток». «Виконувати як: я», «Доступ: будь-хто». Розгорнути й скопіювати URL, що закінчується `/exec`.
5. Відкрити URL: має повернутися JSON з `checked_at`, `state`, `changed_at`, `source_status`. Надати URL для підключення до дашборда.

Тригер `everyMinutes(5)` запускається приблизно кожні 5 хвилин, точність не гарантується. Публічні повідомлення можуть бути неповними або відсутніми. У випадку мережевої помилки перевірка не оновлює `checked_at`, щоб сайт не сприймав старий стан за актуальний. Стан стосується **лише ЖК «Данія»**, а не всієї групи 5.2.

Після надання URL треба оновити `index.html` для читання JSONP із Google Apps Script; до цього кроку сайт продовжує користуватися старим JSON у GitHub.
