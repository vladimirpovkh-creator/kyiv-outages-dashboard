# Автоматичний стан світла ЖК «Форум Празький», черга 5.2

Джерело — тільки Telegram-тема 63 групи `@ForumPrazkyi`.
На сайті немає Telegram-посилань; показуються лише визначені повідомленнями
`Світло є`, `Світла немає` або `Статус невідомий`.

## Читання без прав адміністратора

Учасник групи може **окремо** авторизувати Telethon-сесію через Telegram API.
Для цього необхідні власні `api_id` і `api_hash` з
https://my.telegram.org/apps, а також згенерована локально `StringSession`
для Telegram-акаунта, який має доступ до теми 63.

Задайте у **GitHub → Settings → Secrets and variables → Actions**:
- `TELEGRAM_API_ID`
- `TELEGRAM_API_HASH`
- `TELEGRAM_SESSION`

**Не надсилайте код входу, номер телефону, пароль або StringSession у чат і
не додавайте їх у репозиторій.** StringSession дає доступ до Telegram-акаунта;
для цього сценарію краще використовувати окремий мінімально привілейований акаунт.

Після налаштування секретів вручну запустіть `Forum Prazkyi topic 63 power monitor`
через Actions → Run workflow і перевірте
`data/forum-prazkyi-status.json` (без секретів). Подальші перевірки
заплановані кожні 5 хвилин; GitHub Actions може запускати їх із затримкою.

Неможливість прочитати групу, неавторизована сесія або відсутність однозначних
свіжих повідомлень означають **невідомий стан**, а не припущення про світло.
Повідомлення мешканців не є показаннями лічильника або офіційними даними ДТЕК.
